Welcome to MediaReducer
Automatic media library cleanup for Plex and Jellyfin
v{{ app_version }}{% if app_build %} · build {{ app_build }}{% endif %} · early alpha, expect bugs
This app deletes media files — there is no recycle bin. It starts paused and deletes nothing. Use Simulate until the output matches exactly what you expect before you turn on Automatic Cleanup.
Do not expose this app to the internet. There is no login — anyone who can reach the web UI can delete your media. Keep its port on your LAN or behind a VPN, and never forward it from your router.
Quick start
  1. Open Configuration → Connections: pick your servers, use Auto Detect, then Check for Errors.
  2. Media Library Paths: add the folders MediaReducer may manage and protect any collections.
  3. Arm at least one Space Threshold — all start off, and Monitor Only needs one — then open Filtering & Scoring to allow movies and/or TV and tune the scoring.
  4. Run Simulate from the Dashboard and read the log — Monitor Only switches on by itself once the scan finishes.
  5. Turn on Automatic Cleanup only when Simulate deletes exactly what you'd delete yourself.
  6. Optional: add Notifications to get a summary of each run.
About

MediaReducer scores every movie and TV season from watch history and IMDb rating, and frees space by deleting the lowest-value ones first when your storage thresholds are crossed. Protected collections, filtered titles, and anything it can't safely identify are always skipped. Reopen this guide any time with the ? button in the header; full documentation is in the README.
